# 海報筆記

[English](poster-notes.md)

透過「更多型別 → 海報（Beta）」建立可編輯海報。在普通筆記操作選單選擇「製作海報」，會用標題及選中文字（未選中時取正文前 240 字）建立獨立海報筆記，原筆記保留。

Web 和桌面端開啟獨立設計工作臺，提供 40 套可選模板、12 種平臺畫幅、內建的中英文字型、主標題／副標題／標籤自動排版及真實渲染的模板預覽。版式引擎改編自 MIT 許可的 Qiaomu Design，原始碼及署名位於 `apps/web/src/lib/poster-design`；字型許可隨字型檔案提供。轉換向量模板時省略生成的柵格顆粒紋理。

畫布支援文字、標籤、形狀、曲線、手繪和圖片；多選、編組、對齊吸附、縮放和平移；圖層排序、顯示隱藏和鎖定；字型排版、描邊、陰影、漸變及圖片適應／裁切／翻轉。可按 1～3 倍輸出 PNG、JPEG 或 WebP（每邊不超過 8192 畫素），複製 PNG 或插入原筆記。直接在畫布上編輯文字，模板面板不再提供獨立文案表單。應用模板時沿用當前畫布文案重新排版，並保留獨立新增的元素；撤銷可恢復之前的佈局。直接編輯元素時保留當前排版。

AI 統一使用通用助手右側欄，海報工作臺不再提供獨立 AI 面板。ACP、外部 MCP 和內建助手共用海報工具。本功能不生成 AI 圖片。

## AI 設計工具

- `get_poster_capabilities` 查詢與編輯器共用的字型、平臺目錄、可選瀏覽器設計模板，以及服務端模板、可編輯欄位、操作限制和渲染可用性。瀏覽器模板編號與四種基礎服務端模板屬於不同能力，不能互換其版式。
- `create_poster_memo` 用短文案和基礎模板建立合法可編輯源稿。`list_memos`、`search_memos` 支援 `poster: true` 篩選；`get_poster` 返回畫布幾何與元素編號。
- `update_poster` 必須傳入 `get_poster` 返回的版本，支援 `dryRun` 預演。`edits` 開放字型、斜體、下劃線、行距、字距、顯示隱藏、圖片裁剪／翻轉、形狀、描邊、陰影及漸變；可將陰影、漸變、裁剪或標籤樣式設為 `null` 移除。圖片必須是屬於當前筆記的有效圖片資源。
- 有序 `operations` 支援元素新增、刪除、複製，圖層排序，編組／解除編組，未旋轉元素相對畫布對齊，以及顯式鎖定／解鎖。先執行欄位修改，再執行操作，因此修改鎖定元素的欄位前需在先前呼叫中解鎖；同一次操作列表也可以顯式解鎖後再執行後續操作。`canvas` 可選擇是否縮放元素，`platform` 使用共用平臺規格；拒絕縮放鎖定元素。
- `operations: [{op: "apply_template", template: "bold"}]` 用基礎服務端模板替換**全部**元素，保留主要文案。必須有使用者明確換模板的請求，存在鎖定元素時拒絕。與瀏覽器編輯器的模板應用不同，此操作不會保留獨立新增的裝飾元素。
- `get_poster_preview` 向 MCP 和多模態助手返回當前已儲存預覽的真實圖片內容，修改後清除舊預覽引用。沒有預覽時返回 `browser_render_required`，工具不會重新渲染圖片。`export_poster` 匯出可編輯 JSON 源稿或當前已儲存預覽，不是全解析度重渲染。讀取預覽需要 `read:resources` 和 `read:memos`，上限 4 MiB。新圖片由線上桌面／Web 客戶端和內建字型渲染，服務端不執行 Fabric。
- `request_poster_render` 排隊生成新 PNG 預覽（長邊最高 1600 畫素、最多 4 MiB）；可選 `templateId` 應用完整設計模板，像編輯器一樣保留獨立新增的裝飾。需要 `write:memos` 和 `write:resources`，傳入 `get_poster` 返回的版本。已登入桌面／Web 工作區每 15 秒領取任務，無需開啟該海報。`get_poster_render_job` 返回 pending／rendering／completed／failed，只有完成才代表渲染成功。無線上客戶端時等待，未領取任務 10 分鐘過期，領取後 2 分鐘過期。跨客戶端獨佔領取，儲存事務同時校驗租約和筆記版本，衝突不會覆蓋新源稿。鎖定元素阻止更換模板。完成／失敗任務保留七天，在建立新任務時清理。全解析度 PNG／JPEG／WebP 匯出仍使用編輯器。
- `trash_memos` 按查詢獲得的準確編號移入回收站，`restore_memos` 恢復。普通 `update_memo` 可以修改後設資料，不能替換海報內容。

## 源稿與儲存

`PosterDocument` 是經過校驗、有版本號的源稿，與 Fabric.js 狀態分離。源稿儲存在 Markdown 的 `edgeever-poster-v1` 註釋中，可讀文字和 PNG 預覽用於通用檢視。圖片元素引用工作區附件編號，不接受任意 URL 或任意 Fabric 物件 JSON。進入海報編輯器後才載入渲染引擎。

儲存沿用筆記版本、內容摘要和編輯會話校驗。每個畫布版本儲存獨立的、寬度不超過 480 畫素的預覽圖；僅修改標題等後設資料時複用預覽。歷史預覽保留供版本恢復使用，因此附件用量隨儲存的畫布版本增加。源稿儲存失敗時只清理本次未提交的預覽。

草稿在當前裝置備份。草稿基於另一版本時，需要先下載並核對，不能靜默覆蓋當前筆記。新增圖片和儲存新預覽需要聯網；離線修改保留為本機草稿。插入原筆記時校驗其當前版本，並把成品作為原筆記自己的附件儲存。

## 相容與上線

Android 和 iOS 展示可讀預覽與文字，並禁止把海報當作普通富文字編輯。API 同樣拒絕舊客戶端丟失海報源稿的儲存請求。該門禁需要更新後的伺服器；舊客戶端連線舊伺服器時沒有這個保護。通用 MCP `update_memo` 不能替換海報內容。

不需要資料庫遷移，也沒有修改認證或升級配置。回滾介面時撤下新建／編輯入口，保留源稿、附件與只讀保護；不要把海報轉換為普通筆記或刪除源稿標記。

驗證覆蓋源稿往返、格式校驗、預覽儲存失敗、SQLite 中的版本衝突與舊 contentJSON 覆蓋請求、移動端讀取策略，以及本機 Web 新建／編輯／儲存／重開／匯出與插回原筆記。原生硬體、已安裝桌面端跨版本鏈路與付費 AI 生圖仍需單獨進行釋出驗證；本功能不實現生圖。

瀏覽器渲染迴歸頁：執行 `bun run dev` 後開啟 `/tests/poster-design.html`，檢查每套模板在 12 種平臺畫幅下的渲染、源稿往返、多選變換及 AI 文字對比度。
