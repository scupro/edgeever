# EdgeEver 官方外掛市場上架政策

[English](plugin-marketplace-policy.md)

EdgeEver 官方外掛市場僅收錄自由及開源外掛。本政策適用於外掛進入官方市場並繼續透過官方市場分發，不限制使用者直接透過 GitHub 或 Manifest 地址安裝其他外掛。

## 開源要求

對於提交到市場的每個版本，外掛開發者必須：

- 將 EdgeEver 客戶端中執行的完整原始碼託管在公眾無需帳號或特別權限即可檢視的公開倉庫中。
- 提供 OSI 認可的開源許可證，允許使用、審查、修改和再分發。開發者負責確保所選許可證與外掛包含的全部程式碼及依賴相容。
- 公開人類可讀且未經混淆的原始碼、構建配置，以及能夠合理生成分發包的構建說明。只公開編譯、壓縮或打包後的 `main.js` 不符合要求。
- 讓市場版本對應一個公開且不可變的 Git Tag 或 Commit，並確保 Manifest 和 Release 資產可以追溯到該原始碼版本。
- 標明打包到外掛中的第三方程式碼，並遵守相應的許可證及原始碼提供要求。

在對應原始碼保持公開且可審查的前提下，可以分發壓縮或打包後的資產。僅在獨立託管服務中執行的程式碼無需開源，但外掛詳情必須明確披露對該服務的依賴、傳送的資料、隱私政策及任何付費要求。

無程式碼主題必須公開完整 Manifest，並使用允許公眾使用、審查、修改和再分發的許可證；其中包含的第三方材料也必須採用相容條款。

## 持續上架資格

只要某個版本仍透過官方市場分發，其倉庫、許可證、對應原始碼版本和構建資訊就必須持續公開。如果外掛不再滿足本政策、釋出資產無法追溯到宣告的原始碼，或者其行為帶來安全、隱私、法律或可靠性風險，EdgeEver 可以拒絕上架、暫停分發或下架該外掛。

市場“已驗證”僅表示外掛在稽核時透過了適用的准入與完整性檢查，不代表 EdgeEver 保證外掛絕對安全、沒有錯誤或適合所有使用者。

## 社群目錄

社群目錄沿用同樣的收錄含義。它與內建官方列表分開發布，簽名後的社群檔案也不能接管官方外掛更新。直接透過 GitHub 或 Manifest 地址安裝的路徑保持可用，那條路徑不經過收錄檢查。
