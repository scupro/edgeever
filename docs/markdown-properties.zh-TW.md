# Markdown 筆記屬性

文字筆記支援檔案開頭的 YAML Front Matter 屬性頭。在 Web 與桌面端富文字檢視中，它顯示為可摺疊的「筆記屬性」面板。僅已有屬性頭的文件顯示該面板；普通筆記不增加屬性入口。需要新增屬性時，可在 Markdown 原始碼中編寫屬性頭。面板支援文字、字串列表（每行一個值）、數字、核取方塊和日期。巢狀屬性保留可讀展示，可透過 YAML 原始碼編輯。面板原始碼按鈕與 Markdown 編輯器操作同一份文件資料。

```markdown
---
title: 研究筆記
tags: [archive, research]
source: https://example.com/article
author: [Alice, Bob]
published: 2026-10-10
description: 簡短摘要
custom:
  reviewed: true
---

這裡開始是筆記正文。
```

匯入 `.md` 或 `.markdown` 檔案時，會讀取屬性頭的 `title` 和 `tags`。未提供有效標題時使用檔名。其他屬性、註釋與巢狀值保留在文件中。修改屬性中的 `title` 和 `tags` 會同步現有筆記欄位；修改原有欄位時，也會同步已經存在的對應屬性。刪除屬性僅將它從文件中移除，不會刪除對應的應用欄位。

單篇匯出（包括卡片右鍵匯出）對普通筆記僅匯出正文，不新增屬性頭。文件已有屬性頭時保留原有屬性，並更新已存在的標題和標籤，不額外新增系統欄位。選中筆記與完整 ZIP 匯出生成一個屬性頭，包含自定義屬性和當前筆記後設資料。應用中的標題、標籤、筆記本、建立與更新時間、置頂狀態和 ID 優先於匯入的副本。這些系統屬性（標題和標籤除外）在面板中只讀；修改 YAML 中的副本不會改變應用狀態。`published` 為獨立、可編輯的釋出日期。匯入 `edgeever_id` 不會覆蓋已有筆記。

非法 YAML、重複鍵、未知 YAML 型別標籤、超過 64 KiB 的屬性頭或過度的別名展開，會顯示錯誤並保留原文供修正。無效屬性頭匯出時保持原樣，避免丟失原始碼；修正為有效屬性頭後才合併應用後設資料。普通 Markdown 分隔線、常規 YAML 程式碼示例和未閉合的屬性頭不會被識別為屬性。屬性不計入正文摘要和字數。

## 相容與回滾

屬性使用現有 `codeBlock` 文件節點及 `edgeever-frontmatter` 語言標記，無需資料庫遷移。舊客戶端會顯示 YAML 程式碼塊；舊編解碼器可能將它序列化為圍欄程式碼塊，新編解碼器能再次識別並匯出為 Front Matter。撤回面板或回滾客戶端後，這種可讀形式仍保留。

已使用真實 `v1.105.0` 原始碼檢查「新版 → 舊版編輯 → 新版」編解碼往返。這不能替代打包後的 macOS、Windows、Linux、Android USB 真機跨版本測試；釋出前仍需完成應用級跨版本驗證。Android 原生編輯器目前顯示屬性程式碼塊，尚未提供 Web 屬性面板。

本功能不包含 Obsidian Vault 檔案同步、屬性專用檢索、整個知識庫統一的屬性型別登錄檔或完整的 Obsidian 專屬 Markdown 擴充套件支援。
