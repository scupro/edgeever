# Hacker News 剪藏

開啟 `https://news.ycombinator.com/item?id=<id>` 主帖詳情頁，點選外掛的“剪藏當前網頁”，或在頁面上右鍵選擇“儲存 Hacker News 主帖到 EdgeEver”。工具欄操作優先儲存選中文字；專用頁面右鍵選單儲存主帖。

筆記保留頁面提供的標題、作者、原始釋出時間、剪藏時的分數、外部連結和主帖正文。支援 Ask HN、Show HN 和只有連結的主帖，不包含評論。完整主帖筆記帶有 `web-clip` 和 `hacker-news` 標籤。

外鏈文章僅記錄連結，不抓取其正文。缺失的後設資料直接省略；評論詳情頁、已刪除主帖和無法讀取的內容會被拒絕。剪藏期間頁面切換會取消儲存。不增加持久網站訪問權限。

正文圖片沿用現有附件流程。複製失敗或達到數量限制時，正文仍保留，提示會說明部分圖片仍使用外部連結；併發編輯不會被覆蓋。

## 驗證範圍

自動驗證使用脫敏的公開 HN DOM 樣本，包括解析器測試、實際打包的後臺與注入指令碼測試，以及連線本機 API 並重新開啟筆記的 Chromium 外掛測試。圖片儲存用例在 HN 樣本中加入合成圖片。這些檢查不能替代 Chrome、Edge、Firefox 的真實網站驗收或商店釋出。
