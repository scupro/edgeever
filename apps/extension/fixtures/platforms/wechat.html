什麼是Deepseek V3


DeepSeek-V3 為杭州深度求索人工智慧基礎技術研究有限公司在2024年12月26日釋出的自研的（ MoE 模型，671B 引數，啟用 37B，在 14.8T token 上進行了預訓練。這些看不懂就不要看！）。

DeepSeek-V3 多項評測成績超越了 Qwen2.5-72B 和 Llama-3.1-405B 等其他開源模型，並在效能上和世界頂尖的閉源模型 GPT-4o 以及 Claude-3.5-Sonnet 不分伯仲。

什麼是DeepSeek R1


 DeepSeek-R1 於 2025 年 1 月 20 日釋出，效能對標 OpenAI 的 O1 正式版。DeepSeek-R1 遵循 MIT 許可，允許使用者透過蒸餾技術利用 R1 訓練其他模型。它還上線了 API，開放思維鏈輸出，使用者只需設定 

model='deepseek-reasoner' 

即可呼叫。思維鏈是 AI 領域的核心技術之一，類似於人類做事前的思考過程，AI 透過思維鏈可以更像人類一樣理性地思考和解決問題。

  

R1 開源許可統一採用 MIT 許可，完全開源，不限制商用，無需申請。同時，產品協議明確支援“模型蒸餾”，進一步推動技術開源和共享。這對各大模型廠商來說，無疑是一個衝擊。現在，透過少量 GPU 和“模型蒸餾”就能實現與超大規模引數模型相媲美的效果，真是一個巨大的突破！

DeepSeek V3 和 R1 的主要區別體現在開源、技術特點和應用場景上。DeepSeek V3 作為第三代版本，注重提升模型的通用性和處理能力，適合大規模資料處理和多工學習，應用範圍更廣。而 DeepSeek R1 則完全開源，採用 MIT 許可，支援蒸餾技術，允許使用者利用少量 GPU 訓練高效的模型，並引入“思維鏈”技術，使得 AI 在推理過程中更像人類思考問題。

DeepSeek R1 主要針對那些需要高效 GPU 使用和資源有限環境下的高效能訓練與推理，因此在一些推理效率要求較高的應用場景中表現優異。

DeepSeek V3 更側重於多工和大資料處理，而 R1 則專注於資源最佳化和高效訓練。

以上沒看懂，沒關係，接下來教大家如何在華為雲上使用滿血版的DeepSeek  V3和R1。

 


華為雲ModelAart Studio（MaaS）


 ModelArts Studio（MaaS）是華為雲推出的模型即服務平臺，支援從資料準備到模型部署的全流程操作。最近，平臺進行了重磅更新，新增支援昇騰適配版滿血模型（引數達到671B），並且每個模型還提供200萬免費tokens。這意味著使用者可以在更強大的計算力支援下，進行大規模模型訓練和推理，同時享受免費的 tokens 使用，極大降低了使用門檻和成本。

DeepSeek-R1-671B-32K DeepSeek-V3-671B-32K DeepSeek-R1-671B-8K DeepSeek-V3-671B-8K DeepSeek-V3-671B-4K DeepSeek-R1-671B-4K

 

 第一步：註冊華為雲賬號

華為雲官網：www.huaweicloud.com

點選右上角“註冊”，按要求填寫即可。

1. 註冊後，登入

2.在控制檯右側的區域，選擇“西南-貴陽一”

3.在左上角“三”處點選，搜尋“model”

在左側點選“ModelArts Studio”


 第二步：領取免費tokens

進入ModelArts Studio大模型即服務平臺

點選“模型部署”，在右側點選“領取”

點選“呼叫”，獲取API地址，模型名稱等資訊
下面以模型“DeepSeek-R1-671B-32K”為例：
點選“管理API Key”，新增API Key。
點選“建立API Key”
輸入“描述”，點選“確定”。
複製“金鑰”。
 

 第三步：安裝cherry studio

官網下載：https://cherry-ai.com/download 

網盤下載：https://pan.baidu.com/s/14y1VgCzG9hnrgIkZbSnELA?pwd=7i4w

下載對應版本安裝即可。

第四步：配置並使用cherry studio

安裝後，點選左下角的工具 -> 模型服務 -> 點選“新增”。

提供商名稱：華為雲（可以是其他名字）

提供商型別：OpenAI（這是是通用標準）

點選確定。

1.把前面建立API Key的金鑰貼上到“API金鑰”
2.API地址為第二步點選“呼叫”中的API地址，在結尾新增“#”，比如：
https://infer-modelarts-cn-southwest-2.modelarts-infer.com/v1/infers/xxxe/v1/chat/completions#
3.點選“新增”

模型，模型名稱，分組名稱都是：DeepSeek-R1，點選“新增模型”。

點選“檢查”，彈窗點選“確定”。

等待連線測試結果。

如果連線失敗，檢查以下地方：

1.API金鑰是否複製正確；

2.API地址末尾是否有“#”；

3.模型名稱是否正確。


選擇模型進行對話：

1.點選左上角的聊天按鈕

2.更換模型為剛剛新增的DeepSeek-R1

至此，可以體驗由華為雲昇騰AI晶片提供的滿血版DeepSeek R1！
